01 / THE FUNDAMENTALS

先理解三个词，
再谈怎么买。

“服务器”“VPN”“节点”经常一起出现，但分别回答不同的问题。先把它们拆开。

A / COMPUTER

VPS 虚拟专用服务器

你按月租一台运行 Linux 的云端电脑，有 CPU、内存、硬盘、公网 IP，可以自己安装软件。

回答：“软件运行在哪里？”

B / TUNNEL

VPN 虚拟专用网络

在你的设备和 VPS 之间建立加密通道。选择全局出口时，网站看到的是 VPS 出口 IP。

回答：“流量经过哪里？”

C / ROUTE

线路 网络路由

同一座机房可能走不同运营商、不同国际出口。延迟、晚高峰丢包、拥塞往往比多两核 CPU 更关键。

回答：“数据怎么走过去？”

i

自建 VPN 不会自动提供匿名性，也不保证网站解锁、降低跨洋延迟或绕过公司网络政策。VPS 服务商仍是基础设施的信任方。

DECODING THE PRODUCT NAME

看懂一串商品名，就不怕选错。

LAX地区.AN5硬件.T1线路.V2C2G规格

读作：洛杉矶 · AN5 计算平台 · Tier 1 网络 · VOLUME 系列 2 核 2GB 内存。
历史产品可能带有 PVM. 前缀或不同系列名字，以购买页面的正式产品条款为准。

同是 AN5.T1，为什么又分 VOLUME 与 GENERAL？ VOLUME（型号常以 V 开头）在相近价位通常侧重更大的流量额度；GENERAL（G 开头）则可能提供更多内存。以官网这两款为例：V2C2G 是 2 核、2GB 内存、5000GB 标示流量（$14.90/月）；G2C4G 是 2 核、4GB 内存、4000GB 标示流量（$16.90/月）。两者都属于洛杉矶 AN5 Tier 1 系列，不代表不同的机房或网络线路。具体限额、计费与端口条件须看完整 SKU。
规格表常见词：vCPU / Core 是分配的处理器核心，RAM 是运行内存，Storage / NVMe 是云端磁盘，Transfer 是每个计费周期的流量配额，Port / Gbps 表示标示端口带宽上限；IPv4、IPv6 是不同的公网地址协议。购买 VPN 用 VPS 时，先看线路、流量与 IPv4 是否可用，再比较 CPU、内存和存储。

04 / BUILD YOUR OWN

真正动手搭建，
大概要做什么？

只为自己的设备使用，可以先走简单路线；需要完全控制 WireGuard 的服务端密钥和配置，再选手动路线。

30–60 min熟悉 VPS 的用户：较快走通 Tailscale Exit Node（估算）
1–3 h熟悉 Linux 的用户：手动 WireGuard 安装、排错（估算）
半天新手：补上 SSH、防火墙与网络基础（估算）

Tailscale：较少的网络配置

服务器作为你自己的 Exit Node（出口节点）。它通常使用 WireGuard 加密技术，但设备认证和控制面依赖 Tailscale 服务。

官方步骤 ↗
  1. 买 VPS，安装 Ubuntu LTS。

    优先月付、确认有 IPv4、保存初始登录方式。不要复用研究服务器。

  2. 使用 SSH 密钥登录，并安装 Tailscale。

    从官方 Linux 安装页面选择你的系统；拒绝来路不明的“VPN 一键脚本”。

  3. 在 VPS 上开启转发，并声明出口节点。

    先登录 Tailscale 账号完成设备授权，再执行下面的命令。

    printf 'net.ipv4.ip_forward = 1\nnet.ipv6.conf.all.forwarding = 1\n' | sudo tee /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf
sudo tailscale set --advertise-exit-node
  4. 去 Tailscale 管理台批准出口节点。

    在 Machines → 对应 VPS → Edit route settings 勾选 Use as exit node。

  5. 在 iPhone / Mac 的 Tailscale App 里选择出口。

    用查询公网 IP 的网站检查出口是否变成 VPS 的 IP，再检查 DNS 与 IPv6 路径。

适合初次体验；它属于“自己租的出口服务器 + 第三方设备管理”，不是完全独立的 VPN 控制面。

WireGuard：真正掌控自己的配置

服务器和客户端各自有私钥/公钥，VPS 在指定 UDP 端口监听。示例仅供理解，不能将占位符原样运行。

官方快速入门 ↗
  1. 安装 Ubuntu LTS，准备安全的 SSH 登录。

    先验证 SSH 密钥能从新窗口登录，再考虑关闭密码登录；先放行 SSH，再调整防火墙。

  2. 安装 WireGuard 并安全生成密钥。
    sudo apt update
sudo apt install -y wireguard
sudo install -d -m 700 /etc/wireguard
sudo sh -c 'umask 077; wg genkey > /etc/wireguard/server.key; wg pubkey < /etc/wireguard/server.key > /etc/wireguard/server.pub'

    私钥只留在受保护的设备或服务器，不要写进公开仓库或截图。

  3. 编写 /etc/wireguard/wg0.conf。

    监听 UDP 51820；服务器地址可用 10.77.0.1/24。每个客户端使用不同密钥和内网地址，Peer 的 AllowedIPs 仅填写该客户端的 /32。

  4. 开启 IPv4 转发与 NAT。

    用 ip route get 1.1.1.1 确认实际公网网卡名称（可能是 eth0、ens3 等）；再配置持久化 IP forwarding、NAT 和防火墙。绝不能照搬别人的网卡名称。

  5. 放行 UDP 51820 并启动服务。
    sudo systemctl enable --now wg-quick@wg0
sudo wg show
sudo systemctl status wg-quick@wg0

    仅在 wg0.conf 和转发规则完整且验证过之后运行；云控制台安全组也要匹配。

  6. 在官方 WireGuard 客户端导入配置。

    客户端 Peer 的 Endpoint 是 VPS_IP:51820。全隧道 IPv4 常用 AllowedIPs=0.0.0.0/0；IPv6 要单独配置或明确阻止泄漏，不能误认为自动覆盖。

  7. 验证并维护。

    从手机切换 Wi-Fi/蜂窝网络，检查握手、出口 IP、DNS/IPv6 泄漏，记录配置备份位置并定期安装安全更新。

这是一份安全学习路径，不是“一键部署脚本”。防火墙、NAT、SSH 和 IPv6 的实际值需要按自己的 VPS 确认后填写。

06 / FREQUENT QUESTIONS

第一次买 VPS，
还容易踩哪些坑？

先弄懂边界，能少花钱、少折腾。

买了 VPS，VPN 就自动能用了吗？+

不能。VPS 只是云服务器，你仍需安装和配置 WireGuard、Tailscale 等软件，完成防火墙、客户端和出口测试。

DMIT 线路越贵，访问新加坡就越快吗？+

不一定。Premium 主要体现为特定中国方向的优质路由。美国到新加坡的表现，应从你实际所用的美国 ISP、目标服务与时段测量 RTT、丢包和速度。

有 10Gbps 端口，我就能跑到 10Gbps 吗？+

不是。那通常是商品写明的端口标称能力，不代表单连接吞吐承诺。加密、CPU、对端线路和拥塞都会降低实测速度。

VPN 能让我匿名，或让所有网站都以为我是当地居民吗？+

不能保证。它改变常见情况下的公网出口，并加密设备到 VPS 的路径；网站仍可通过账号、浏览器指纹、DNS 等判断其他信息。有些平台会识别并限制数据中心 IP。

怎么判断选错了？+

先月付，连续在白天与晚高峰测试至少几天，记录延迟、丢包、流量、目标服务可用性和断线次数。若 CPU 与内存很空闲，升级它们通常不会修复线路问题。

能直接把我原来 Stash 的配置放进这个公开仓库吗？+

不要。订阅 URL、认证凭据、节点地址、WireGuard 私钥与真实配置均应保存在私有且受保护的位置。科普项目只存脱敏示例。
