# Build, publish, and acceptance

Architecture: pure static HTML/CSS/vanilla JS; Node.js standard-library-only build; GitHub Actions for build/test; GitHub Pages for hosting. No third-party packages, tokens or analytics.

## GitHub Pages first deployment

1. GitHub Settings → Pages → Build and deployment → Source: GitHub Actions.
2. Commit .github/workflows/pages.yml to main (push triggers run).
3. Confirm verify job passes, deploy job succeeds and github-pages environment returns a URL.
4. Open the URL and test: desktop/mobile layout; navigation anchors; 10 data-backed selected price rows; each network filter; Tailscale/WireGuard tabs; traffic calculator; copy controls; official source links.
5. Verify HTTPS and display URL before claiming website is live.

Actions needs contents:read. The deploy job additionally needs pages:write and id-token:write. Artifact uploads the dist directory generated by npm run check.

## Local QA

~~~bash
npm run check
python3 -m http.server 8080 --directory dist
~~~
